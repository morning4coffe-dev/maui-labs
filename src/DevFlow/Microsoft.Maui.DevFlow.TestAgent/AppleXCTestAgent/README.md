# Native XCTest bundle

`DevFlowAppleTestAgent.xcodeproj` is a source-only XCTest/XCUITest skeleton for iOS
Simulator, Mac Catalyst, and the separately labeled experimental AppKit/macOS lane. It uses Xcode already installed on the QA Mac; the repository
does not install Xcode, runtimes, workloads, signing identities, or profiles.

The bundle reads these inherited, ephemeral environment variables at runtime:

- `DEVFLOW_APPLE_AGENT_ENDPOINT`
- `DEVFLOW_APPLE_AGENT_SESSION_ID`
- `DEVFLOW_APPLE_AGENT_SESSION_SECRET`
- `DEVFLOW_TARGET_BUNDLE_ID`
- `DEVFLOW_TARGET_APP_DIGEST`
- `DEVFLOW_APPLE_IN_APP_AGENT_PORT`
- `DEVFLOW_APPLE_TEST_SEED`

The secret is an HMAC key generated by the host script, never committed, printed, or
written to artifacts. The host also binds the command target to the launched process and app
digest. The test project has no target-app dependency: `XCUIApplication` attaches by the exact
approved bundle identifier and starts the explicit integration-test seed only in the Debug test
build. AppKit evidence is experimental, carries `backend=appkit`, and never substitutes for
Mac Catalyst coverage.
